# camel-groovy-dsl-common

No Javadoc is published for this artifact. Its sources are Groovy, which the Java
`javadoc` tool does not process. This jar is a placeholder, because Maven Central
requires a `-javadoc.jar` for every jar that contains classes.

Source code and documentation: https://github.com/Nordix/camel and https://camel.apache.org/
